# Deploying the project homepage

1. The repository has been created at `chengxiaoen/AG-IoT-OpenSet-IDS`.
2. Upload this release candidate to the `main` branch.
3. In GitHub repository settings, open **Pages**, choose **Deploy from a branch**, select `main`, and select `/docs` as the folder.
4. Wait for deployment, then confirm that `https://chengxiaoen.github.io/AG-IoT-OpenSet-IDS/` opens on a logged-out browser.
5. Add the public URL to the paper only after it is confirmed.

The homepage includes no analytics, cookies, trackers, or download of raw data. It links users to the original Farm-Flow dataset record instead.
