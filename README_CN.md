# AG-IoT 开放集入侵检测：开源包说明

这是论文的**公开前候选开源包**，用于复现冻结的训练、校准、评估和结果汇总流程。

当前最重要的规则：论文声明采用“可观测属性完全相同的重复组隔离”划分，因此公开版本只应使用本包的 grouped protocol；不要将早期逐行随机划分脚本称为论文的复现脚本。

本包不含 Farm-Flow 原始 CSV、模型、逐条预测、日志或特征缓存。数据须从原始 Zenodo 页面自行下载，并遵守提供方条款。具体位置、命令和限制见 `docs/REPRODUCIBILITY.md` 与 `docs/DATASET.md`。

在 GitHub Pages 真正部署成功、链接可公开访问且通讯作者完成清单核对前，不要把 `Code:` 链接写回论文 PDF。
